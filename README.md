DocMust - Premium Resume Maker
DocMust is a modern, lightweight, and feature-rich web application designed to help users build clean, professional, and ATS-optimized resumes instantly. Built with vanilla HTML, CSS, and JavaScript, it features a seamless real-time split-screen builder that updates a live A4 preview canvas as you type.

✨ Key Features
1. Real-Time Split-Screen Preview: Watch your changes instantly render onto a responsive, standard A4-proportioned paper preview layout.

2. ATS-Optimized Templates: Choose from multiple professional layouts, including the highly-coveted Harvard Classic template engineered to bypass Applicant Tracking Systems and maximize callback rates.

3. Multi-Step Guided Workflow: An intuitive 6-step progression tracker that breaks resume creation down into manageable sections (Profile Info, Work Experience, Education, Skills, Additional Info, and Design).

4. Dynamic Accent Colors: Instantly customize the look and feel of your resume using preset professional swatches or a custom color picker.

5. Dark and Light Mode: Fully integrated theme toggling for a comfortable workspace environment.

6. Local Data Persistence: Automatic session saving via browser local storage ensures you never lose your progress.

7. Instant PDF Export: Powered by html2pdf.js for quick, high-quality document generation directly from the browser.

8. Quick Demo Engine: A built-in "Load Sample Data" feature that populates the form with realistic professional data instantly.

🛠️ Tech Stack
1. HTML5 for semantic document structure

2. CSS3 (with CSS Variables for dynamic styling and theme control)

3. Vanilla JavaScript (ES6+) for reactive UI rendering and state management

4. html2pdf.js for client-side PDF generation.
